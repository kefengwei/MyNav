    就绪

    数据来源：data/links.js。改完点「下载 JSON」覆盖 data/links.json，再运行 node tools/build-data.mjs；或直接「发布到 GitHub」，CI 会自动生成。

    发布到 GitHub

    需要 fine-grained token：Repository access 只勾这个仓库，Permissions → Contents 选 Read and write。 Token 只存在本机浏览器（localStorage），不会写进仓库，也不会发给除 api.github.com 以外的地址。

    从收藏夹导入

    支持浏览器导出的书签文件：Chrome / Edge / Firefox / Safari 的 HTML，或 Chromium 的 Bookmarks JSON。 书签文件夹会变成分类，同名分类自动合并，重复网址自动跳过。
